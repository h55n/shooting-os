# Seed-data checklist

Do not fabricate these. Populate from real source material:

- Father profile and verified credentials.
- 3–5 authentic voice samples.
- Coaching philosophy and vocabulary.
- Verified shooting fundamentals, safety, equipment, performance and pathway documents.
- Verified personal story timeline.
- Existing ideas, approved scripts and published content.
- Trend keywords/source configuration.

All documents should carry verification status and source metadata before becoming generation context.
